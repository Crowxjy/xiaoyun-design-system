# 政策计算器 Demo

## 需求快照
- 目标：根据本地保存页 `/Users/bytedance/Downloads/政策计算器` 复刻 `https://crm.dylk.com/m/webview/policy_calc/policy` 的核心页面结构与主交互。
- 落点：`demo/policy-calculator-mobile/index.html`
- 约束：沿用销运标题规范，优先消费 `@xiaoyun-ds/components-web` 公共组件，并兼容移动端浏览。

## 复刻范围
- 保留原页核心骨架：顶部 Hero、区域选择、计算器/规则说明双页签、输入区、结果区、规则说明区。
- 保留核心规则口径：T+5 结算、扫码返佣门槛、灵活佣金新开/存量档位、次月续约锁档、本地推 +10%、点击触发重算。
- 保留结果表达：扫码免佣、扫码返佣、灵活佣金三块结果，对客话术、结果反推、提报动作。
- 补充移动端适配：双列布局在窄屏折叠为单列，避免原页桌面结构在手机上发生内容挤压与错位。

## 组件选型
- `PageHeader`：承接 Hero 区标题与说明。
- `Tabs`：承接“计算器 / 规则说明”双页签切换。
- `Capsule`：承接商家身份与高频类目快选。
- `Select`：承接区域、类目以及续约判断项选择。
- `Input`：承接金额与日期输入。
- `Checkbox`：承接本地推 +10% 开关。
- `Button`：承接开始计算、清空、复制和提报跳转动作。
- `Tag` / `Tags`：承接状态标签与提示信息。
- `MetricCard`：承接三大板块和关键指标结果。
- `Diagnosis`：承接对客话术、结果反推和提报动作建议。

## 规则映射
- 区域：直接复用本地规则文件中的 6 个全量开放区域。
- 门槛：复用 `miaoda_rules.js` 中的硬规则分组门槛。
- 灵活佣金：复用新开 40/60/80 与存量 50/60/70 两套档位。
- 类目：复用保存页真实下拉选项；由于离线规则文件未直接吐出完整类目费率树，本 demo 采用“真实类目列表 + 门槛分组 + 常见费率映射”的方式重建。

## 与原页差异
- 原页存在更完整的离线类目树与费率明细；本 demo 已保留主要类目和主规则，但费率映射为近似复刻，不作为最终提报依据。
- 原页的结果文案更长、更细；本 demo 保留了核心表达结构，并收敛为适合移动端阅读的版本。
- 原页存在更多辅助面板与隐藏联动字段；本 demo 只保留对核心测算有直接影响的字段。

## 自检结果
- 页面骨架：已生成单文件 HTML，可直接本地预览。
- 组件来源：使用 `@xiaoyun-ds/components-web` 公共组件承接核心交互。
- 标题规范：页面标题与一级标题走项目级公共标题规范。
- 移动端适配：提供断点折叠，输入区与结果区在窄屏自动改单列。
- 数据交互：点击“开始计算”后才产出结果，输入变化会标记“待重算”。

## 预览方式
- 直接打开 `demo/policy-calculator-mobile/index.html`
- 或在仓库根目录启动静态服务后访问 `/demo/policy-calculator-mobile/`
