对客话术与提报动作

    规则说明

    仅基于 design.md 与 token 表达；移动端会折成单列。

    T+5 提醒

    返佣按结算 GMV 算，不按当天核销算；月底核销往往顺延到下月。

    类目判断顺序

    先判不适用类目，再判扫码免佣 / 扫码返佣，最后再看灵活佣金。

    底线门槛

    扫码返佣按类目硬拦截：休闲娱乐 1000 元，餐饮 / 医美 / 本地服务等主流类目 2000 元。

    扫码返佣口径

    返佣比例固定 100%，返的是软件服务费，0.6% 通道费不返。

    灵活佣金档位

    新开按 5000 / 2w / 3w 对应 40% / 60% / 80%；存量按增量 1w / 2w / 3w 对应 50% / 60% / 70%。

    移动端

    窄屏下输入区、结果卡片、规则卡自动折成单列；表单元素行高与按钮统一 40px。

    本页仅消费项目 token 与 design.md 约定，未引入 components.css；适用于演示设计系统 token 层的独立可用性。
